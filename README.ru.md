<h1 align="center">BrowserPicker</h1>

---

Назначьте BrowserPicker браузером по умолчанию. Когда вы нажмёте ссылку в Telegram, Slack, почте,
терминале или любом другом приложении, рядом с курсором плавно появится небольшая скруглённая
панель со списком установленных браузеров. Выберите браузер мышью или клавишей, и ссылка
откроется в нём.

## Возможности

- **Нативный вид.** На macOS используется системный материал popover (vibrancy) со скруглёнными
  углами и нативной анимацией появления. На Windows панель в стиле Fluent с мягкой тенью.
- **Плавность.** Пружинные анимации появления, подсветка, которая скользит между браузерами,
  каскадное появление элементов, анимация запуска. Учитывается настройка «Уменьшить движение».
- **Управление с клавиатуры.** `1`–`9` сразу открывают браузер, стрелки или `Tab` + `Enter`
  выбирают, `Esc` закрывает панель, `⌘C` / `Ctrl+C` копирует ссылку.
- **Не мешает.** Приложение не отображается в Dock и на панели задач. Значок в трее или строке
  меню можно отключить. После закрытия окна настроек приложение продолжает работать в фоне.
- **Автозапуск.** При входе в систему приложение запускается тихо, без окон.
- **Порядок браузеров задаёте вы.** Браузеры находятся автоматически. Их можно переставлять
  перетаскиванием и скрывать ненужные. Если виден только один браузер, ссылка открывается
  в нём сразу, без панели.
- **Лёгкий.** Rust + [Tauri 2](https://tauri.app) на системном WebView (WebKit на macOS,
  WebView2 на Windows). Без Electron и встроенного Chromium, без JS-фреймворков и сборщика для UI.
  Установщик весит несколько мегабайт. Окно настроек при закрытии уничтожается, и в памяти
  остаётся только маленькое заранее загруженное окно выбора. Поэтому оно появляется мгновенно.

## Установка

Скачайте свежий `.dmg` (macOS) или `-setup.exe` (Windows) на странице
[Releases](https://github.com/asmnpl/BrowserPicker/releases).

**macOS 12+.** Перетащите BrowserPicker в «Программы» и запустите. Сборки пока не нотаризованы,
поэтому при первом запуске нажмите на приложение правой кнопкой и выберите **Открыть**
или выполните:

```sh
xattr -dr com.apple.quarantine /Applications/BrowserPicker.app
```

**Windows 10/11.** Запустите установщик. Установка идёт для текущего пользователя, права
администратора не нужны.

Затем нажмите **Make Default** в окне настроек:

- На **macOS** система попросит подтвердить смену браузера по умолчанию.
- На **Windows** откроется страница «Приложения по умолчанию». Выберите BrowserPicker для
  `HTTP` и `HTTPS` или нажмите «Установить по умолчанию».

## Управление

| Действие | Как |
| --- | --- |
| Открыть ссылку в браузере | Щелчок или `1`–`9` |
| Переместить выбор | `←` `→` `↑` `↓`, `Tab` / `Shift+Tab`, `Home` / `End` |
| Открыть выбранный браузер | `Enter` или `Пробел` |
| Скопировать ссылку | `⌘C` / `Ctrl+C` или кнопка копирования |
| Закрыть | `Esc` или щелчок в любом другом месте |
| Открыть настройки | Значок в трее или строке меню, или повторный запуск приложения |

## Сборка из исходников

Нужны [Rust](https://rustup.rs) (stable), [Node.js](https://nodejs.org) 18+ (только для Tauri CLI)
и [зависимости Tauri](https://tauri.app/start/prerequisites/) для вашей ОС.

```sh
npm install
npm run dev      # запуск в режиме разработки
npm run build    # сборка .app/.dmg или NSIS-установщика в src-tauri/target/release/bundle
```

Подробности об устройстве проекта описаны в [README.md](README.md#how-it-works).
